### Паттерны

1. Interpreter

Паттерн Interpreter в проекте использован для интерпретации пользовательских вводов, таких как координат выстрелов. Например, при вводе координаты "B3" или "a1" на игровое поле, применяется Interpreter, чтобы он интерпретировал введенное значение как клетку.

2. Chain of Responsibility

Паттерн Chain of Responsibility устанавливает связь между объектами, которые последовательно обрабатывают запросы. В проекте этот паттерн использован для обработки запросов на выстрел в игровом поле, добавления и удаления кораблей.

Например, имеется цепочка из нескольких объектов: gameProcess, player, myField/enemyField. Каждый объект обрабатывает запрос на выстрел, если ответственность за такой запрос лежит на нем. Если объект не может обработать запрос, он передает его следующему объекту в цепочке.

3. Singleton

Паттерн Singleton означает, что объект создается только один раз и затем используется один и тот же экземпляр везде в программе. В проекте таким объектом является gameProcess, он создается один раз для осуществления различных функций.
