Авторы проекта: Малышева Полина, Голубцова Дарья

Название проекта: Battleship

Игра "Морской бой"

Поле: 10x10

Корабли: 4 1-палубных корабля, 3 2-палубных корабля, 2 3-палубных корабля, 1 4-палубный корабль.

Игра для двух участников, в которой игроки сначала расставляют корабли на своем поле,
после этого по очереди вводят координаты на карте соперника.
Если у врага с этими координатами имеется "корабль", то корабль или его палуба убивается, попавший делает еще один ход.
Если у врага с этими координатами нет корабля, то ход переходит к сопернику.
Если у одного из игроков все корабли убиты, игра заканчивается.
Цель игрока: первым убить все игровые "корабли" врага.

Требования к ПО: java 11; maven 3.9.1

Команда для сборки: mvn package
Команда для запуска: java -jar project_tp-1.0-SNAPSHOT.jar
